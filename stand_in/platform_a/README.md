# WardWatch (fictional stand-in platform)

Predicts deterioration (unplanned ICU transfer within 48 h) for adult ward admissions, scored once at the prediction time, 6 h after admission. All data are synthetic and generated by the platform itself.

## Commands (run from this folder)

1. Generate the synthetic extract into `data/`: `python -m wardwatch generate --config config.yaml`
2. Train and evaluate: `python -m wardwatch train --config config.yaml`
3. Score new admissions: `python -m wardwatch predict --config config.yaml --input-dir DIR --output preds.csv`
   (DIR holds patients.csv, admissions.csv, vitals.csv and labs.csv for the new admissions)
4. Tests: `python -m pytest -q`

## Outputs (in `outputs/`)

- `split.csv`: admission_id, patient_id, split (train or test)
- `test_predictions.csv`: admission_id, patient_id, label, risk_score, alert
- `metrics.json`: auroc, auprc, brier, threshold, sensitivity, specificity, n_test, n_events
- `model.joblib` and `model_meta.json` (feature list, threshold, model hash)

## Data

- Patient id column: `patient_id`; admission id column: `admission_id`
- Target: `deteriorated_48h` in admissions.csv; prediction time: `prediction_time` in admissions.csv
- Timestamps: admissions (admit_time, prediction_time, discharge_time, icu_transfer_time); vitals (charttime); labs (charttime)
- Inference input ranges: heart_rate 20-250 /min, resp_rate 4-60 /min, sbp 40-300 mmHg, temp_c 30-45 °C, spo2 50-100 %, lactate 0.1-30 mmol/L, creatinine 10-2000 µmol/L, wbc 0.1-200 x10^9/L
